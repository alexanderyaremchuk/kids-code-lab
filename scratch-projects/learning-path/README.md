# Scratch Learning Path

Short, playable lessons for kids who already know the Scratch editor and a few
basic blocks. Each lesson starts with a working program, then asks the child to
read it, predict what a change will do, edit one thing, and test the result.

## Lessons

1. [Catch the Star](01-catch-the-star/README.md) — keyboard events, movement,
   a forever loop, sensing, random positions, and a score variable.
2. [Dodge the Meteor](02-dodge-the-meteor/README.md) — falling motion,
   coordinates, comparisons, lives, scoring, and game-over state.
3. [Robot Dance Party](03-robot-dance-party/README.md) — broadcasts, parallel
   scripts, repeat loops, costume animation, timing, and graphic effects.
4. [Neon Maze Escape](04-neon-maze-escape/README.md) — colour sensing,
   backdrop-driven rules, coordinates, combined conditions, and bump tracking.

## Suggested progression

1. Control a character and collect an object.
2. Add an obstacle, lives, and a game-over message.
3. Coordinate several sprites with broadcasts and parallel animation.
4. Build a maze using coordinates and touching-colour sensing.
5. Make a short quiz using broadcasts and variables.
6. Design a small original game by combining earlier ideas.

Keep each lesson short: play first, inspect the blocks, change one feature,
then explain what the changed block controls.
