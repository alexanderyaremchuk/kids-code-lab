# Lesson 1: Catch the Star

## Goal

Move a spaceship with the arrow keys and catch the star to earn points.

Open [Lesson 01 - Catch the Star.sb3](Lesson%2001%20-%20Catch%20the%20Star.sb3)
in Scratch using **File → Load from your computer**.

## Blocks to notice

- **when green flag clicked** sets the starting positions and resets the score;
- **when key pressed** moves the spaceship;
- **forever** keeps checking for a catch;
- **touching Explorer Ship?** detects the collision;
- **change Score by 1** rewards the player;
- **pick random** chooses the star's next position.

## First modification

Change the spaceship's movement amount from `12` to `20`. Before running the
game, ask: will the ship become faster or slower? Test the prediction.

## Extra challenges

1. Make each catch worth two points.
2. Change the star's message.
3. Change the game's colours or draw a new spaceship costume.

## Quick check

- Which block makes the program keep checking for a collision?
- Why does the star move after the score changes?
- What happens if the random-position ranges are made smaller?
