# Lesson 05 — Balloon Pop

A tiny clicker game for practising a complete Scratch game loop without too
many moving parts.

## Play

1. Open `Lesson 05 - Balloon Pop.sb3` in Scratch.
2. Press the green flag.
3. Click the balloon five times.
4. Each click changes its colour and moves it somewhere new.

## What the program teaches

- **Events:** start with the green flag and react to a sprite click.
- **Variables:** keep the score and reset it before every game.
- **Random movement:** use `go to random position`.
- **Decisions:** use `if/else` to decide whether the player has won.

There is only one sprite and two short scripts. Read the green-flag script
first, then read the click script from top to bottom.

## Small challenges

Try one change at a time:

1. Make the player pop eight balloons instead of five. Remember to change both
   the winning number and the opening message.
2. Change how much the balloon's colour changes after each click.
3. Add a second costume and switch costumes whenever the balloon is clicked.

After each change, press the green flag and explain which block changed the
game's behaviour.
