# Lesson 3: Robot Dance Party

## Goal

Press the Space key once and make three robots dance at the same time.

Open [Lesson 03 - Robot Dance Party.sb3](Lesson%2003%20-%20Robot%20Dance%20Party.sb3)
in Scratch using **File → Load from your computer**.

## New concepts

- **broadcast dance** sends one message to the whole project;
- **when I receive dance** starts a script on each robot and the stage;
- the receiving scripts run **in parallel**;
- **repeat 6** makes a short, controlled animation loop;
- **next costume** creates pose animation;
- **wait** controls the rhythm;
- colour effects animate the stage without changing its artwork.

## First modification

Change one robot's **repeat 6** block to **repeat 10**. Predict which robot will
keep dancing after the others stop, then press Space to test it.

## Extra challenges

1. Make one dancer move faster by reducing its wait time.
2. Invent a different movement for the pink robot.
3. Add a fourth sprite and give it a **when I receive dance** script.
4. Create a second broadcast named `freeze` that returns everyone to position.

## Quick check

- Why do all three robots begin without calling each one separately?
- What is the difference between **repeat** and **forever** here?
- Which block changes the speed of the dance?
