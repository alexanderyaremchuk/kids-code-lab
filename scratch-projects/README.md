# Scratch Projects

Reusable Scratch animations and learning games for the kids project.

## Projects

- [Simple Rocket Animation.sb3](Simple%20Rocket%20Animation.sb3) — a first
  animation with movement, direction changes, and costume changes.
- [Fraction Pizza Challenge.sb3](Fraction%20Pizza%20Challenge.sb3) — a
  ten-round visual fractions game with clickable answers, feedback, and score
  tracking.
- [Scratch Learning Path](learning-path/README.md) — short, playable coding
  lessons that begin with a working program and continue with small challenges.
- [Balloon Pop](learning-path/05-balloon-pop/README.md) — a deliberately simple
  one-sprite game: click the balloon five times to win.

## Open a project

1. Open the [Scratch editor](https://scratch.mit.edu/projects/editor/).
2. Choose **File → Load from your computer**.
3. Select the `.sb3` file.

Add future Scratch files to this folder and list them above with a one-line
description.
